원문: https://ethancho12.substack.com/p/anthropic-and-the-inverse-gacha (2026-05-19)

## 핵심
- 파워유저 토큰 압박을 **inverse gacha**로 프레이밍: Max/$200 유저를 쥐어짜면 게임처럼 churn이 아니라 **대체**(Kimi/Codex/local)로 간다.
- 일화: 3인 팀이 Codex ~100 인스턴스로 OpenAI API **$1.3M / 30일**.
- Max 플랜 5시간 창이 ~90분에 소진된다는 보고.
- Perel Web Studio: Claude Max 오케스트레이터 + Kimi K2.5 overflow (~$0.90/MTok), $150–300/mo로 Anthropic API 대비 수배 비용 커버.
- 함의: 멀티모델/라우팅·프롬프트 이식성 툴이 수혜; 단일모델 앱은 마진 리스크.
