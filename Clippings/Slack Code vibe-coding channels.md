## Slack Code

2026-08-20 공식. Slack Code는 슬랙 안에서 팀과 AI 에이전트가 같이 만드는 방식이다. 아이디어나 기능, 웹페이지 수정, 버그 수정이 있으면 코딩 에이전트를 태그한다. 그 에이전트가 전용 코드 채널을 연다.

채널에서 팀과 에이전트가 대화를 보고, 코드 디프를 감사하고, 산출물 라이브 프리뷰(HTML 포함)를 보고, 피드백을 주고, 승인 뒤에 나간다. 프로젝트별 코드 채널, 전용 유저 탭이 있다. 과제가 끝나면 채널이 자동 아카이브되고 감사 로그가 남는다.

슬랙 업데이트(2026년 8월) 문구: Slack Code is a new way of building with AI in Slack. Bring your team into a code channel to plan, prompt, and review together while a supported agent brings your visions to life.

같은 달 Agents & tools 사이드바 페이지, 에이전트 스레드 시각·이름 붙은 스레드·네이티브 정지 버튼이 같이 올라왔다.

## 파트너와 플랜

마켓플레이스 에이전트와 동작한다. 론칭 파트너로 Claude Code, Devin, Vercel Agent, GitHub Copilot이 코드 채널에 붙는다고 했다. 보도·소개에 ChatGPT도 태그 대상으로 나온다.

전 플랜. 당일부터. 에이전트 이용권은 각자다.
