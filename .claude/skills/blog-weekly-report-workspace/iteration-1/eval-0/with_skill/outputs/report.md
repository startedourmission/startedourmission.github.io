> [!summary] 2026-W24 한 주 요약
> 이번 주 게시 7편, 전부 논문 리뷰입니다(월 5편, 화 2편). 화요일까지의 집계라 모델 릴리스·툴·산업·잡담 슬롯은 아직 공백이고, 에이전트 메모리와 추론 트레이스 진단이라는 두 주제로 글이 또렷이 쏠렸습니다.

## 월요일 · 논문
### [논문] [[The Self-Correction Illusion - LLMs Correct Others but Not Themselves]]
- 태그: 추론, 에이전트
- LLM 에이전트가 자기 추론 속 오류는 못 고치면서 같은 주장이 외부 출처로 붙으면 잘 고치는 비대칭을, 대만 국립성공대 연구진이 통제 실험으로 파헤친 논문입니다. 틀린 주장을 바이트 단위로 동일하게 둔 채 감싸는 역할만 self에서 external로 옮기면 명시적 교정률이 23~93%p 뛰었습니다. 결론은 자기 교정 실패가 능력 결함이 아니라 채팅 템플릿의 역할 라벨 아티팩트라는 것. 학습 없이 쓸 수 있는 신뢰성 레버를 던지는 글이라 읽을 만합니다.

### [논문] [[ReasoningFlow - Discourse Structures for Understanding LLM Reasoning Traces]]
- 태그: 추론, LLM
- 추론 모델이 토해내는 길고 비선형적인 사고 트레이스를, UIUC 연구진이 8종 노드와 14종 엣지의 방향성 비순환 그래프로 파싱하는 프레임워크 ReasoningFlow를 내놨습니다. 1,260개 트레이스를 분석한 결과, 오류 스텝의 14.4%만 틀린 최종 답에 인과적으로 기여했고 79.6%는 아예 최종 답과 연결조차 안 됐다는 점이 충격적입니다. 오류 탐지를 잘해도 성능이 곧장 안 오르는 이유를 설명하는, 추론을 길이가 아니라 구조로 들여다보는 도구입니다.

### [논문] [[MARDoc - A Memory-Aware Refinement Agent Framework for Multimodal Long Document QA]]
- 태그: 멀티모달, 에이전트
- 수백 페이지짜리 멀티모달 문서를 읽는 QA 에이전트가 상호작용 기록을 하나의 거대한 맥락에 계속 쌓다 핵심 증거를 노이즈에 묻히는 문제를, 톈진대 연구진이 탐색·정제·반성 세 에이전트가 구조화된 메모리로 소통하는 Explore-Refine-Reflect 루프로 풉니다. 증거 메모리와 추론 메모리를 분리해 오류 출처를 추적하게 한 것이 핵심입니다. 오픈 Qwen3-30B만으로 폐쇄형 Claude 3.5 Sonnet 기반 DocAgent와 맞먹고, DocBench에서는 사람 기준선마저 넘겼습니다.

### [논문] [[Holo3.1 - Fast and Local Computer Use Agents]]
- 태그: 에이전트, 멀티모달, 오픈소스
- 화면을 보고 클릭하는 컴퓨터 유즈 에이전트를 클라우드가 아니라 내 기기에서 돌리는 데 초점을 맞춘 H Company의 릴리스입니다. 모델을 0.8B부터 35B-A3B까지 네 크기로 내고, 프로덕션급으로는 처음으로 FP8·NVFP4·Q4 GGUF 양자화 체크포인트를 함께 출하했습니다. 4B 한 개로 100배 큰 Qwen3.5 397B를 종합 점수에서 넘기고, 4-bit 양자화로 12GB GPU에서 돌며 RTX 4090에서 140ms 지연을 냅니다. 온디바이스 GUI 자동화를 현실로 끌어내린 글입니다.

### [논문] [[Autoregressive Diffusion World Models for Off-Policy Evaluation of LLM Agents]]
- 태그: 에이전트, 강화학습
- 새 LLM 에이전트를 실제 환경에 굴리지 않고 과거 로그만으로 성능을 가늠하는 오프폴리시 평가 프레임워크 ADWM을, 에모리대와 상하이교통대 연구진이 내놨습니다. 월드 모델 자체를 디퓨전 과정으로 세우고, 정책 유도 궤적 법칙을 단일 스텝 조건부로 정확히 분해해 기존 디퓨전 OPE를 막던 순환 의존을 끊은 것이 핵심입니다. 네 개 멀티턴 벤치마크 여섯 구성에서 ADWM만 모든 셀에서 양의 순위 상관(평균 +0.82)을 내, 에이전트 A/B 테스트 비용을 줄이는 실전 도구로 읽힙니다.

## 화요일 · 모델 릴리스
### [논문] [[Generative Criticality in Large Language Model Temperature Scaling]]
- 태그: LLM, 머신러닝
- 물리학자들이 LLM의 temperature 슬라이더를 통계물리의 상전이로 들여다본 논문입니다. 토큰 임베딩을 스핀 변수로 놓으면, 임계온도 약 1.4 근처에서 출력의 질서와 무질서가 물의 끓는점처럼 급변하는 임계 현상이 나타납니다. susceptibility 급첨두, order parameter 붕괴, 내재 차원 최소라는 서로 독립적인 세 신호가 같은 지점을 가리키는데, 이는 정확도 지표로는 보이지 않는 집단 통계 구조입니다. 무질서 상의 급격한 시작을 출력 신뢰성의 경계 지표로 삼을 수 있다는 관점을 여는 탐색적 작업입니다.

### [논문] [[Agent Memory - Characterization and System Implications of Stateful Long-Horizon Workloads]]
- 태그: 에이전트, LLM
- 에이전트에 기억을 붙이는 일을 정확도가 아니라 시스템 비용의 문제로 처음 해부한 논문입니다. 메모리 시스템을 네 패러다임으로 분류하고, 구축·검색·생성 단계별로 토큰과 GPU 에너지를 측정해 열 개 시스템을 비교합니다. 정답 하나를 만드는 데 드는 에너지가 시스템 간 약 45배 벌어지며, 그 비용 대부분이 사용자 눈에 안 보이는 기억 구축 단계에 숨어 있다는 것을 보입니다. 에이전트 메모리 선택은 정확도가 아니라 시스템 결정이라는 메시지가 또렷합니다.
