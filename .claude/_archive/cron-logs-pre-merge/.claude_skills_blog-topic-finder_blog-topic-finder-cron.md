#### 1. ABot-AgentOS: A General Robotic Agent OS with Lifelong Multi-modal Memory
- arXiv: https://arxiv.org/abs/2607.10350
- 기관: Robbyant (분산 저자진)
- 주목도: HF 74 upvotes · buzz 50 · 2026-07-11 제출
- 핵심: 현재 VLM/VLA 시스템이 지각·행동은 개선했지만 장기 에이전트에는 추론·메모리·검증·크로스 바디 실행 레이어가 없다는 문제에서 출발. ABot-AgentOS는 (1) scene-conditioned 플래닝, (2) context-isolated 스킬 실행, (3) 멀티모달 그래프 메모리(대화·시각·공간·시간·태스크 트레이스를 typed 지식 구조로 변환), (4) edge-cloud 협업, (5) 멀티스테이지 검증을 하나의 OS 레이어로 통합한다. EmbodiedWorldBench 신규 벤치마크: 16개 실내/외/혼합 씬, 난이도 4단계, 200+ 태스크(내비게이션·오브젝트 탐색·NPC 대화·동적 이벤트·트레이스 기반 채점).
- 글로 풀 포인트: "로봇 에이전트에게 OS가 필요한 이유" — VLM이 잘하는 지각과 VLA가 다루는 행동 사이에 있는 빠진 계층을 설명. 멀티모달 그래프 메모리 아키텍처가 기억 일관성을 어떻게 유지하는지, EmbodiedWorldBench의 채점 방식이 기존 벤치마크와 어떻게 다른지.
