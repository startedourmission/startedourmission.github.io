## 1. Goal

**Verify whether the pipeline**

> scan wallets → detect “smart money” signals → paper-copy into a virtual book → measure paper PnL

**can be prototyped on Grok Bot as a lab**, not as a live trader.

### Success looks like (lab, not alpha)

- A repeatable bot/routine loop that:
  1. Pulls **public** transfer/swap activity for a curated watchlist.
  2. Emits **structured signal rows** (schema below) with source URLs.
  3. Updates a **$50 paper portfolio** with explicit fee/slippage assumptions.
  4. Produces a **falsifiable** equity curve and signal count after a fixed window (e.g. 7 days).

### Explicit framing

| This lab **is** | This lab **is not** |
|---|---|
| A concept recreation of AstraDEX-style *wallet scan → copy signal* ideas | AstraDEX, Astra copy-trading, or any product equivalence claim |
| A paper PnL sandbox on the Grok Bot box | A path to live execution or “smart money alpha” |
| An architecture + schema + acceptance test | Financial advice or a profit claim |

**Null hypothesis (to falsify):**  
*“On this box, with public explorers only, we cannot sustain ≥N logged signals and a coherent paper equity series over 7 days.”*  
If we fail acceptance criteria, the prototype is **invalidated for ops readiness** — not “the market doesn’t work.”

### 2.1 Data sources (public only)

**Primary concepts (no credentials invented):**

| Source concept | Role | Notes |
|---|---|---|
| **Block explorer HTTP / HTML** (Etherscan-family, Basescan, Arbiscan, etc.) | Address tx lists, token transfers, internal txs | Rate-limit politely; prefer documented free API tiers if a *user-supplied* public key exists later — MVP can scrape public pages or use no-key endpoints only |
| **Public RPC read endpoints** (community / chain defaults) | `eth_getLogs`, receipt decode for swaps | Read-only; never signing |
| **Public DEX subgraph / indexer mirrors** (The Graph public endpoints, Dune public queries if available) | Swap events, pool marks | Treat as best-effort; cache locally |
| **Public price oracles / free mark feeds** (CoinGecko public, DefiLlama prices, explorer USD hints) | Mark-to-market for paper positions | Document which feed is used per asset |
| **Public “leader / whale” leaderboards** (third-party public sites that list profitable wallets) | Seed candidates for watchlist | Human-reviewed; do not auto-trust rankings |

**Connector concepts that *might* help later (names only — do not provision secrets):**

- Browser / fetch connector for explorer pages  
- Scheduled shell/cron-style routine on the box  
- Optional: authenticated *read* API only if the lab operator pastes a **free-tier public explorer API key** into a local env file the bot never invents or exfiltrates  

**Hard ban list for data plane:** private keys, seed phrases, CEX trading API secrets, deposit addresses used for funding, “execute trade” endpoints.

### 2.2 Smart-money watchlist construction

**Seed (MVP):** 5–15 manually curated EOAs on **one chain** (recommend Base or Ethereum mainnet for explorer maturity). Prefer wallets that appear on *public* PnL leaderboards or known public research lists — always store `source_url` for each seed.

**Inclusion criteria (v0 scoring — transparent, not magical):**

1. **Activity:** ≥K swaps or token transfers in the last 30 days (K default: 10).  
2. **Size filter:** at least one transfer/swap notional ≥ $X in USD marks (X default: $1,000) — filter noise, not “whales only.”  
3. **Diversity:** not a known CEX hot wallet / bridge / router (maintain a deny-list of public contract addresses).  
4. **Persistence:** address still active in last 7 days.  
5. **Optional quality proxy (v1):** simple realized-PnL heuristic on recent closed round-trips *if* reconstructable from public transfers — labeled `heuristic_only`, never “proven edge.”

**Refresh cadence:**

| Cadence | Action |
|---|---|
| Daily | Re-check activity + deny-list; drop dead addresses |
| Weekly | Re-score; propose adds/drops in a digest for **human approve** |
| Ad-hoc | Operator pastes a new address + source URL into watchlist JSON |

### 2.4 Paper portfolio

**Starting capital:** `$50.00` USD virtual cash.  
**State file:** `/workspace/paper-trader-lab/portfolio.json`  
**Ledger:** `/workspace/paper-trader-lab/fills.jsonl`  
**Marks series:** `/workspace/paper-trader-lab/equity.jsonl` (daily close + optional per-signal)

**Position model (simple MVP):**

- Cash + long-only spot tokens (no leverage, no perps in MVP).  
- On signal `buy`: spend `size_notional_paper` from cash (capped by available cash and per-trade max).  
- On signal `sell`: reduce position by paper notional or by %-of-position rule.  
- **Never** allow cash &lt; 0; skip or resize if insufficient.

**Default copy sizing (MVP):**

- Per-signal paper notional: `min($5, 10% of equity, available_cash)`.  
- Max concurrent positions: 5.  
- Max single-asset weight: 40% of equity at fill.

**Fees assumption (document in every report):**

- Round-trip fee: **30 bps** (0.30%) of notional per fill side → **15 bps** each way, *or* flat **30 bps on notional at each fill**. Lab default: **20 bps per fill** (buy and sell each).  
- Rationale: deliberately slightly harsh vs. ideal DEX fee so paper PnL is not flattered.

**Slippage assumption:**

- **50 bps** adverse vs. mark at signal time for MVP fills.  
- Optional v1: scale slippage with `onchain_notional_usd` (larger whale prints → assume worse paper fill).

**Marking:**

- End-of-day (or end-of-scan) mark using the chosen public price feed.  
- Equity = cash + Σ(position_qty × mark).  
- Store fee + slippage drag separately so “gross vs net paper” is visible.

### 2.5 Bot / routines (conceptual prompts & triggers)

All routines run **on the box**, paper-only, and never call signing or order APIs.

#### A. Daily scan routine

- **Trigger:** scheduled daily (e.g. 09:00 KST) or manual “run scan now.”  
- **Prompt / job concept:**  
  > Load `watchlist.json`. For each active wallet, fetch public txs since `last_cursor`. Classify swaps/transfers. Emit signal rows matching thresholds. Deduplicate by `signal_id`. Append to `signals.jsonl`. Run paper engine on new signals. Append equity snapshot. Write `daily_scan_report.md`.

#### B. Alert-on-signal

- **Trigger:** after scan, if new signals ≥ 1.  
- **Concept:** short digest: wallet, asset, side, paper size, source_url.  
- **Channel:** lab-local markdown / Slack-style message *only if* the operator already wired a non-trading connector — default is file drop under `/workspace/paper-trader-lab/alerts/`.

#### C. Weekly PnL digest

- **Trigger:** weekly (e.g. Monday 09:00 KST).  
- **Contents:** signal count, hit rate of “paper closed trades,” equity curve summary, fee/slippage drag, watchlist churn proposals, **failures and data gaps**.  
- **Tone rule:** no “guaranteed,” no “alpha proven,” no Astra equivalence.

#### D. Watchlist refresh (human-in-the-loop)

- **Trigger:** weekly after digest.  
- **Output:** proposed adds/drops with criteria scores + source URLs.  
- **Gate:** no auto-add without human edit of `watchlist.json`.
