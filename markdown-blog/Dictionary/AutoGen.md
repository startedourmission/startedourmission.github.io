여러 LLM 에이전트가 서로 대화하며 과제를 푸는 오픈소스 프레임워크입니다. 대화 가능한 에이전트를 만들고, 그들이 서로 통신하고 툴을 쓰고 사람 피드백을 받도록 구성하는 고수준 추상을 제공합니다.

마이크로소프트 리서치에서 출발했고 이후 AG2라는 이름의 독립 프로젝트로 이어졌습니다. 월 70만 회 이상 다운로드되고 2만 명 넘는 에이전트 개발자 커뮤니티를 갖고 있습니다.

공동 제작자이자 AG2 공동창업자가 [[우칭윈]]입니다. 여러 에이전트가 역할을 나눠 대화하며 문제를 푸는 구조는 [[From RLVR to RLSVR - Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement]]가 열린 과제를 다중 에이전트 사회추리게임으로 변환하는 발상과 같은 계보에 있습니다.
