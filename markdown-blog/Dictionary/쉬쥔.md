중국인민대학(RUC) 가오링인공지능학원 교수입니다. 난카이대학에서 2001년 학사, 2006년 컴퓨터과학 박사를 받았습니다.

연구 분야는 지능형 정보검색, 추천시스템, 빅데이터 분석입니다. 구체적으로는 learning to rank에 강화학습을 붙이는 방향, 의미 매칭과 관련도 랭킹의 딥러닝, 정보검색에서의 인과추론을 다룹니다.

마이크로소프트 리서치 아시아에서 연구원·수석연구원을 지냈고, 중국과학원 컴퓨팅기술연구소 교수(2014~2018)를 거쳐 2018년부터 중국인민대학에 있습니다. RUC IIR Lab을 이끕니다.

[[ToolArtist - Tool-Using Unified Multimodal Models for Agentic Image Generation]]의 교신저자입니다. 검색 쪽 배경이 이 논문에서 TextSearch·ImageSearch 도구를 단순 API 호출이 아니라 LLM Reader를 낀 요약 파이프라인으로 설계한 대목과 이어집니다.
