## 개요

Midea(미데아, 美的)는 1968년 광둥성 순더에서 창업한 중국 최대 가전 기업입니다. 에어컨·냉장고·세탁기가 주력이지만, 2016년 독일 산업용 로봇 기업 [[KUKA]]를 약 50억 달러에 인수하면서 산업 자동화 쪽으로 사업 축을 넓혔습니다.

## AI 조직

**Midea AI Research Center(AIRC)** 가 AI 연구를 담당합니다. 2026년 들어 "Sema" 계열 하네스 엔지니어링 논문을 연달아 냈습니다.

- SemaClaw (2026-03) - 범용 개인 에이전트를 위한 하네스 엔지니어링
- Sema Code (2026-04) - 코딩 에이전트 코어를 클라이언트에서 분리한 임베더블 인프라
- [[SemaPLC - A Project-Grounded, Verification-Gated Agent Harness for PLC Code Generation|SemaPLC]] (2026-08) - 산업용 [[PLC]] 제어 로직 생성 하네스

세 편 모두 [[왕화찬]]이 교신저자입니다. 가전 회사가 에이전트 하네스 논문을 내는 것이 어색해 보일 수 있지만, KUKA를 소유하고 자사 공장 라인을 직접 굴리는 회사라 생성된 제어 로직이 실제로 도는지가 연구 주제가 됩니다.
