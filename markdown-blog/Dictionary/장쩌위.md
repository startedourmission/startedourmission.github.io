## 개요

Zeyu Zhang은 중국인민대학교 고령인공지능학원(GSAI) 박사과정으로 [[천쉬|Xu Chen]] 교수 지도를 받으며, MemTensor(상하이)에도 소속돼 있습니다. Metis 논문의 공동 1저자입니다.

이 사람의 이력이 곧 Metis의 계보입니다. 2024년 「A Survey on the Memory Mechanism of Large Language Model-based Agents」로 에이전트 메모리 분야를 정리했고(ACM TOIS 게재), 이후 메모리 평가 시뮬레이터 MemSim(NeurIPS)을 냈습니다. 메모리를 외부 모듈로 붙이는 접근을 서베이로 훑은 사람이 그 접근의 한계를 정리해 백본 안으로 넣자고 제안한 셈입니다.

## 업적

- A Survey on the Memory Mechanism of Large Language Model-based Agents (ACM TOIS). LLM 에이전트 메모리 연구의 표준 참고 문헌 중 하나입니다.
- MemSim (NeurIPS). LLM 기반 개인 비서의 메모리를 평가하는 베이지안 시뮬레이터.
- Metis (2026) 공동 1저자.
