## 개요

쩡싱산(Xingshan Zeng)은 [[화웨이]] 노아의 방주 연구소(Noah's Ark Lab) 음성·시맨틱 그룹 연구원입니다. 연구 영역은 자연어처리, 대규모 언어 모델, 그리고 AI 에이전트입니다.

## 생애

홍콩중문대학교 시스템공학·공학경영학과에서 2020년 박사학위를 받았습니다. 박사과정 시절 주제는 대화 구조와 담화 모델링 쪽이었고, 학위 취득 후 노아의 방주 연구소에 합류해 다국어 음성 번역과 기계 번역 과제에 참여했습니다.

## 업적

2024년 이후 관심의 축이 언어 모델 자체에서 에이전트로 옮겨갔습니다. 파운데이션 모델 기반 GUI 에이전트 서베이의 공저자로 참여했고, 이후 도구 사용과 에이전트 학습 데이터 쪽 연구를 이어가고 있습니다.

[[What Makes Good Agentic Data - An ACE Lens on Data Generation for LLM Agents]]에서는 1저자로 참여해, 에이전트 학습 데이터를 $(E, q, \tau, v)$ 네 인자로 쪼개는 공통 표현과 ACE 목적함수를 세웠습니다. 서베이의 골격을 도메인 라벨이 아니라 생성 메커니즘 기준으로 다시 짠 것이 이 논문의 구조적 기여인데, 그 재편의 중심에 있는 인물입니다.
