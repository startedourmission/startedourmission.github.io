[[KUKA]] 그룹 CTO입니다. 2022년 10월 KUKA에 합류해 그룹 CTO를 맡았고, 2023년 5월부터 로보틱스 사업부 CTO를 겸합니다.

칭화대에서 공학 학사와 석사를 받고 펜실베이니아주립대에서 기계공학 박사를 받았습니다. KUKA 이전에는 ABB에서 20년간 제품 관리와 R&D의 여러 리더십 자리를 거쳤습니다. 로보틱스와 자동화 사업 쪽 실무 이력이 길다는 뜻입니다.

[[SemaPLC - A Project-Grounded, Verification-Gated Agent Harness for PLC Code Generation|SemaPLC]](2026-08)의 교신저자 세 명 중 하나입니다. 이 논문이 생성된 제어 로직을 실제 [[PLC]] 런타임에 올려 실행 트레이스를 대조하는 쪽으로 평가 축을 옮긴 배경에는, 정적 채점만으로는 현장에 못 내보낸다는 산업 현장의 관점이 깔려 있습니다.
