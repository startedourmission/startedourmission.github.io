## 개요

Cloudflare OS는 [[클라우드플레어]]가 2026년 8월 5일 Agents Week에서 Apache 2.0으로 공개한 에이전트 워크스페이스입니다. 이름에 OS가 붙었지만 전통적 의미의 운영체제는 아니고, Cloudflare Workers 위에서 조직 구성원이 앱을 만들고 업무를 자동화하고 내부 시스템에 안전하게 접근하게 하는 플랫폼입니다.

## 구조

핵심 개념은 Gadget입니다. 문서나 앱 인스턴스 하나하나가 각자의 샌드박스에서 돌아갑니다. 슬라이드 덱을 만들면 클라우드의 공용 SaaS를 호출하는 것이 아니라 그 문서만을 위한 앱 인스턴스가 새로 뜹니다. 서버 코드는 아웃바운드 네트워킹이 꺼진 Dynamic Worker로 돌고, 클라이언트 코드는 브라우저 샌드박스에서 돕니다. 저장소는 Durable Object Facet과 SQLite를 쓰고, 클라이언트와 서버는 Cap'n Web RPC로 통신합니다.

접근 제어는 Gadget 코드가 아니라 게이트키퍼(Gatekeeper)라는 서비스별 Worker가 담당합니다. 에이전트는 외부 시스템 접근 권한 0에서 시작하고, 자격 증명은 에이전트 코드와 분리돼 있습니다. 그래서 에이전트가 Gadget 코드를 고쳐도 원래 없던 권한이 생기지 않습니다.

모델 호출은 전부 Cloudflare AI Gateway를 거치므로 조직이 태스크 종류별로 사용할 모델과 지출을 통제할 수 있습니다.

## 계보

[[켄턴 바르다]]가 2015년 창업한 Sandstorm의 부활입니다. 앱마다 격리된 인스턴스를 띄운다는 구상은 같았지만 당시에는 컨테이너 오버헤드로 실패했습니다. Dynamic Workers가 컨테이너 대비 100배 효율적이라는 것이 바르다의 설명이고, 코드를 고치는 주체가 사람에서 에이전트로 바뀐 것이 두 번째 변화입니다.

런타임 workerd가 오픈소스라 Cloudflare 의존 없이 로컬 셀프호스팅이 가능하고, 바르다는 로컬 실행이 클라우드보다 빠르다고 밝혔습니다. Ollama 같은 로컬 LLM도 붙습니다.
