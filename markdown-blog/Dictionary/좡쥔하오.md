## 개요

좡쥔하오(庄俊豪, Junhao Zhuang)는 칭화대학교 컴퓨터기술 석사 과정 마지막 학년으로, Chun Yuan 교수의 지도를 받고 있습니다. 연구 관심사는 컴퓨터비전이며 특히 이미지와 영상 생성입니다.

## Self Gradient Forcing에서의 역할

JD의 Joy Future Academy 소속으로 [[Self Gradient Forcing - Native Long Video Extrapolation]]의 1저자입니다. 기존 Self Forcing 패러다임이 자기생성 히스토리를 KV 메모리로 기록하는 계산에 감독 신호를 주지 못한다는 문제, 즉 저자들이 historical context-gradient gap이라 부르는 간극을 짚고 2패스 학습 전략으로 메웠습니다. 코드는 본인 GitHub 계정으로 공개했습니다.

시니어 저자는 [[두안난]]입니다.
