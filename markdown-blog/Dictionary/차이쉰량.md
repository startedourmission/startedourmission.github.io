[[메이퇀]] 수석 연구원(Principal Researcher)입니다. 2007년부터 2017년까지 바이두에서 연구원으로 일한 뒤 2017년 메이퇀에 합류했습니다.

메이퇀의 오픈 모델 계열인 LongCat 기술 보고서 다수에 이름을 올리고 있습니다. LongCat-Flash, 13.6B 규모의 영상 생성 모델 LongCat-Video, 음성 구동 아바타 생성 LongCat-Video-Avatar 1.5, 모달리티를 이산 토큰으로 어휘화한 LongCat-Next 등입니다. 연구 관심사는 대규모 언어 모델, 자연어처리, 추천 시스템, 정보 검색입니다.

[[AgentOPSD - Recursive Self-Distillation for Agentic Reinforcement Learning]]에는 메이퇀 쪽 공저자로 참여했습니다.
