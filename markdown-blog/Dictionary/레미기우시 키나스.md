브로츠와프에 있는 Bielik.ai(SpeakLeash 재단) 연구자입니다. 폴란드어 특화 오픈 LLM Bielik의 DPO 학습과 데이터 준비, RL 학습, 벤치마킹, 양자화를 맡아 왔습니다. Bielik은 폴란드어 문서 4,000만 건으로 학습됐고 AGH 과학기술대 Cyfronet 슈퍼컴퓨터를 썼습니다.

BDH-CQ 논문에서는 Pathway 소속이 아닌 외부 감사자로 참여했습니다. 모델 가중치 접근 없이 문서화된 프로토콜(BDH-ARC-BBX-001)로 배포된 시스템의 ARC-AGI-1 pass@2 29.5%를 재현했습니다. 회사가 자기 모델 점수를 발표할 때 외부 감사를 공저자로 묶는 형태입니다.
