[[중국과학기술대학교]](USTC) 교수입니다. 2009년 같은 학교에서 학사, 2014년 박사학위를 받았습니다.

연구 분야는 추천 시스템, 데이터 마이닝, 공간 데이터 마이닝, 그리고 학습 기반 해싱입니다. 100편이 넘는 논문을 냈고 TKDE와 KDD 등에서 리뷰어로 활동합니다. 대표 연구 중 하나는 pQCF(product Quantized Collaborative Filtering)로, 사용자와 아이템의 결합 잠재 공간을 저차원 부분공간의 카티전 곱으로 분해해 효율과 정확도 사이 균형을 다시 잡은 방법입니다.

[[Repo-To-Skill - Distilling GitHub Repositories Into AI4AI Skills]](2026)의 교신저자입니다. 대규모 후보 집합에서 필요한 것만 빠르게 골라내는 문제를 오래 다뤄 온 이력이, 5,000개가 넘는 스킬을 20개 영역과 178개 능력군으로 색인하고 라우터로 좁혀 들어가는 이 논문의 설계와 맞닿습니다.
