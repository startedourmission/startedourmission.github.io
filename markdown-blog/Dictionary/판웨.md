## 개요

판웨(Lue Fan)는 [[중국과학원]] 자동화연구소 패턴인식 국가중점연구실(NLPR) 소속 연구자입니다. 자율주행용 LiDAR 기반 3D 객체 검출에서 출발해 월드 모델로 영역을 넓혔습니다.

## 연구

단일 스트라이드 희소 트랜스포머 3D 검출기(SST), Fully Sparse Fusion 같은 3D 검출 연구가 초기 계보입니다. 이후 [[왕위치]]와 함께 Drive-WM, 잠재 월드 모델 기반 엔드투엔드 자율주행(ICLR 2025) 같은 자율주행 월드 모델 작업을 이어 왔습니다.

[[PhiZero - A World Model Built Around Physical Language]]에서는 교신저자로 참여했습니다.
