## 개요

판훙위(Hongyu Pan)는 [[AMAP CV Lab]] 소속 연구원으로, ABot-World 팀의 Data 팀을 이끕니다. AAA 게임, 시뮬레이션 엔진, 인터넷 영상이라는 세 갈래 소스를 하나의 액션 표현으로 모으는 데이터 인프라가 담당 영역입니다.

## 생애

세부 이력에 대한 공개 정보는 제한적입니다. [[AMAP CV Lab]]에서 데이터 파이프라인 쪽 역할을 맡아 왔습니다.

## 업적

[[ABot-World-0 - Infinite Interactive World Rollout on a Single Desktop GPU]]의 데이터 인프라를 설계했습니다. 핵심은 데이터 수집을 한 번 끝내는 전처리 단계가 아니라 학습과 맞물려 도는 서보 루프로 바꾼 점입니다. WorldExplorer라는 에이전트가 가상 환경을 스스로 돌아다니며 동기화된 멀티모달 궤적을 모으고, 모델 평가에서 드러난 약한 구간으로 수집 자원을 다시 배분합니다.

여섯 개 품질 차원에 걸친 14개 결정론적 검사와 VLM 기반 의미 판정을 3단계로 배치해, 파일 무결성부터 UI 오버레이·사망 시퀀스·지오메트리 오류까지 걸러내는 필터링 체계도 함께 구성했습니다. 초기 단계에 빠른 형식 검증을 두어 무거운 분석 전에 불량 샘플을 떨어뜨리는 순서 설계가 특징입니다.
