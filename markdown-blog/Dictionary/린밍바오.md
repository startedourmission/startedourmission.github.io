## 개요

린밍바오(Mingbao Lin, 林明宝)는 싱가포르 Kunlun 2050 Research와 Skywork AI 소속 연구자입니다. 신경망을 더 작고 빠르게 만드는 압축 기법, 특히 네트워크 프루닝 분야에서 오랜 기간 성과를 쌓아 왔고, 최근에는 저지연 AI 시스템 쪽으로 관심을 옮기고 있습니다.

## 생애

2022년 [[샤먼대학교]]에서 지능과학기술 전공 박사 학위를 받았습니다. 이후 텐센트 유투랩(Tencent Youtu Lab) 시니어 연구원을 거쳐 현재는 싱가포르에서 [[옌수이청]]과 같은 조직에 속해 연구를 이어가고 있습니다.

## 업적

린밍바오의 초기 연구는 합성곱 신경망 압축에 집중돼 있습니다. Filter Sketch, 1xN Pattern for Pruning Convolutional Neural Networks, Network Pruning using Adaptive Exemplar Filters 같은 작업으로 필터 단위 프루닝의 패턴 설계 문제를 다뤘고, N:M 희소성을 위한 공간 재파라미터화 연구도 발표했습니다. IEEE TPAMI, IJCV, IEEE TIP, CVPR, NeurIPS 등에 논문을 냈습니다.

2026년에는 실시간 음성 상호작용용 기억 시스템인 [[VoiceMem - Streaming Dual-Brain Memory for Real-Time Interaction]]에 교신저자로 참여했습니다. 검색 예산을 top-5로 묶고 지연을 134ms 안에 가두는 이 논문의 설계 방향은 모델을 작게 만들어 온 그의 이전 궤적과 이어집니다.
