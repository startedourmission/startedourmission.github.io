상하이자오퉁대학교 인공지능학원 조교수이자 박사 지도교수입니다. 2021년 난징대학교에서 컴퓨터과학 학사를, 2025년 6월 싱가포르국립대학교(NUS)에서 박사학위를 받았습니다.

박사 과정 내내 데이터셋 증류(dataset distillation)를 했습니다. 큰 데이터셋을 몇 장의 합성 이미지로 압축해도 학습이 되게 만드는 문제입니다. NeurIPS 2022의 Dataset Distillation via Factorization, CVPR 2023의 Slimmable Dataset Condensation, ICCV 2023의 Few-Shot Dataset Distillation via Translative Pre-Training, NeurIPS 2023의 MGDD가 이 계열이고, 2024년 1월 TPAMI에 이 분야 종합 리뷰를 공저했습니다.

관심사는 생성 AI, 특히 합성 데이터로 굴리는 효율적 딥러닝입니다. [[ABSeeker - Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment]]의 교신저자 중 한 명인데, 8,500개 궤적만으로 4B 모델을 30B급까지 끌어올린 이 논문의 데이터 효율 지향은 그의 증류 이력과 맞닿아 있습니다.
