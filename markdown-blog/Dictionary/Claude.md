Claude는 Anthropic이 개발하는 대화형 AI 시리즈입니다. [[다리오 아모데이]]·[[다니엘라 아모데이]] 남매를 비롯해 OpenAI 출신 연구진이 2021년 설립한 Anthropic의 대표 제품으로, AI 안전성(safety)을 핵심 가치로 내세웁니다.

모델 라인업은 작은 순서대로 Haiku, Sonnet, Opus로 구분됩니다. 2024년 Claude 3 시리즈로 본격 경쟁권에 진입했고, 3.5·3.7·4·4.5·4.6을 거쳐 현재 Opus 4.7이 최상위 모델입니다. 코드 작성, 길이 추론, 도구 사용 능력에서 자주 최상위로 평가받습니다.

웹·앱·API 외에도 Claude Code 같은 CLI·IDE 통합, MCP를 통한 외부 도구 연결 등 개발자 생태계에서 특히 강세입니다. RLHF 대신 헌법적 AI(Constitutional AI) 기법을 도입한 것도 [[ChatGPT]]와의 차별화 포인트입니다.
