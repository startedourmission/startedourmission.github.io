듀크대 전기컴퓨터공학과 박사과정으로 Center for Computational Evolutionary Intelligence(CEI) 랩에 있습니다. [[천이란|Yiran Chen]]과 [[리하이헬렌|Hai Helen Li]] 두 사람의 지도를 받습니다.

주력 분야는 LLM 가속과 효율화, AutoML입니다. `Dobi-SVD: Differentiable SVD for LLM Compression`(ICLR 2025)으로 저비용 디바이스용 압축 기법을 냈고, `CoreInfer: Accelerating Large Language Model Inference with Semantics-Inspired Adaptive Sparse Activation`은 NVIDIA Titan XP에서 성능 손실 없이 10.33배 가속을 보고했습니다. `Focus: A Streaming Concentration Architecture for Efficient Vision-Language Models`는 HPCA 2026 베스트 페이퍼 후보에 올랐습니다.

효율화를 하던 사람이 [[From RLVR to RLSVR - Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement]]의 1저자로 나온 것은 방향 전환처럼 보이지만, 외부 검증자 호출 비용을 없애는 것이 이 논문의 실질적 이득 중 하나라는 점에서 이어집니다.
