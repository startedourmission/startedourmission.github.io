## 논문
### [[Generative Criticality in Large Language Model Temperature Scaling]]
- 태그: LLM, 머신러닝
- 물리학자들이 LLM의 temperature를 통계물리 상전이로 해석했습니다. 토큰 임베딩을 스핀으로 놓으면 임계온도 근처에서 출력의 질서와 무질서가 물 끓는점처럼 급변하고, susceptibility 급첨두와 order parameter 붕괴, 내재 차원 최소가 같은 지점을 가리킵니다. 정확도로는 안 보이는 출력 신뢰성의 경계를 제시합니다.

### [[Agent Memory - Characterization and System Implications of Stateful Long-Horizon Workloads]]
- 태그: 에이전트, LLM
- 에이전트에 기억을 붙이는 일을 정확도가 아니라 시스템 비용으로 처음 해부했습니다. 메모리 시스템을 네 패러다임으로 나눠 토큰과 GPU 에너지를 재니, 정답 하나 만드는 에너지가 시스템 간 약 45배 벌어지고 그 비용 대부분이 사용자 눈에 안 보이는 기억 구축 단계에 숨어 있습니다.

### [[The Self-Correction Illusion - LLMs Correct Others but Not Themselves]]
- 태그: 추론, 에이전트
- 자기 추론 오류는 못 고치면서 같은 주장이 외부 출처로 붙으면 잘 고치는 비대칭을 통제 실험으로 규명했습니다. 역할 라벨만 self에서 external로 바꿔도 교정률이 23~93%p 뛰어, 자기교정 실패가 능력 결함이 아니라 채팅 템플릿 아티팩트임을 보입니다.

### [[ReasoningFlow - Discourse Structures for Understanding LLM Reasoning Traces]]
- 태그: 추론, LLM
- 추론 모델의 길고 비선형적인 사고 트레이스를 8종 노드와 14종 엣지의 DAG로 파싱하는 프레임워크입니다. 1,260개 트레이스를 보니 오류 스텝의 14.4%만 실제 오답에 인과 기여하고 79.6%는 최종 답과 연결조차 안 됐습니다. 오류 탐지를 잘해도 성능이 안 오르는 이유를 설명합니다.

### [[MARDoc - A Memory-Aware Refinement Agent Framework for Multimodal Long Document QA]]
- 태그: 멀티모달, 에이전트
- 수백 페이지 멀티모달 문서 QA에서 탐색·정제·반성 세 에이전트가 구조화된 메모리로 소통하는 Explore-Refine-Reflect 루프를 제안합니다. 증거 메모리와 추론 메모리를 분리해, 오픈 Qwen3-30B만으로 폐쇄형 Claude 3.5 Sonnet 기반 DocAgent와 맞먹고 DocBench에서 사람 기준선을 넘겼습니다.

### [[Holo3.1 - Fast and Local Computer Use Agents]]
- 태그: 에이전트, 멀티모달, 오픈소스
- 화면을 보고 클릭하는 컴퓨터 유즈 에이전트를 클라우드가 아닌 내 기기에서 돌리는 데 초점을 둔 릴리스입니다. 0.8B부터 35B-A3B까지 네 크기에 FP8·NVFP4·Q4 GGUF 양자화 체크포인트를 함께 내, 4B 하나로 훨씬 큰 모델을 종합 점수에서 넘기고 12GB GPU에서 동작합니다.

### [[Autoregressive Diffusion World Models for Off-Policy Evaluation of LLM Agents]]
- 태그: 에이전트, 강화학습
- 새 에이전트를 실제 환경에 굴리지 않고 과거 로그만으로 성능을 가늠하는 오프폴리시 평가 ADWM입니다. 월드 모델을 디퓨전으로 세우고 순환 의존을 끊어, 네 벤치마크 여섯 구성 전 셀에서 양의 순위 상관(평균 +0.82)을 냈습니다.

### [[The Deterministic Horizon - When Extended Reasoning Fails and Tool Delegation Becomes Necessary]]
- 태그: 추론, 에이전트
- 긴 사고사슬이 어느 지점부터 정확도를 무너뜨리는지 정보이론적 용량 한계로 증명한 ICML 2026 논문입니다. 19~31스텝의 임계점을 넘으면 신경 추론을 밀어붙이지 말고 도구에 위임하라는 처방을 내놓습니다.

### [[Quantized Reasoning Models Think They Need to Think Longer, but They Do Not]]
- 태그: 추론, LLM
- 양자화하면 정확도는 떨어지고 사고사슬은 길어지는데, 원인이 사고력이 아니라 멈추지 못함이라는 점을 메타 FAIR가 짚었습니다. 학습 없이 로짓 페널티만으로 길이 폭주를 처방합니다.

### [[Audio Interaction Model]]
- 태그: 음성, LLM
- 오프라인 오디오 LLM과 스트리밍 모델을 하나의 always-on 모델로 합친 작업입니다. perceive-decide-respond 루프와 SoundFlow 프레임워크로 듣기와 말하기를 끊김 없이 잇습니다.

### [[Cosmos 3 - Omnimodal World Models for Physical AI]]
- 태그: 멀티모달, 확산모델
- 언어·이미지·비디오·오디오·행동을 하나의 Mixture-of-Transformers로 처리하는 NVIDIA의 옴니모달 월드 모델입니다. 자기회귀 추론 타워와 확산 생성 타워로 VLM·비디오 생성기·월드 시뮬레이터·월드 액션 모델을 한 백본에 흡수합니다.

### [[MMG2Skill - Can Agents Distill In-the-Wild Guides into Self-Evolving Skills]]
- 태그: 에이전트
- 위키하우 같은 사람용 가이드를 에이전트용 SKILL.md 절차로 증류하고, 실행 궤적 진단으로 스스로 고치는 폐루프를 제안합니다.

### [[MetaForge - A Self-Evolving Multimodal Agent that Retrieves, Adapts, and Forges Tools On Demand]]
- 태그: 에이전트, 멀티모달
- Decide·Retrieve·Adapt·Forge 네 단계로 도구를 언제 어떻게 늘릴지 강화학습으로 함께 학습하는 자기진화 멀티모달 에이전트입니다.

### [[HLL - Can Agents Cross Humanity's Last Line of Verification]]
- 태그: 에이전트, 벤치마크
- CAPTCHA를 정답 인식이 아니라 실제 상호작용으로 푸는지로 측정하는 벤치마크입니다. 방해와 궤적 검증을 넣으면 8개 프런티어 에이전트가 무너지는 모습을 드러냅니다.
