> [!summary] 이번 주 (2026-06-22 ~ 06-25) 요약
> 신규 13편(논문 9, 정보 4). 논문은 에이전트 거버넌스·벤치마크(GateMem, PlanBench-XL, AOHP), 확산 언어모델(d-OPSD, PerceptionDLM), VLA·로봇 조작(ACE-Ego-0, DragMesh-2), 효율적 파싱(Unlimited OCR)으로 에이전트와 확산·멀티모달에 무게가 실렸습니다. 정보 글은 AI 데이터센터 전력망(FERC), Sakana Fugu 오케스트레이션, Mastra npm 공급망 공격, ChatGPT 점유율 50% 붕괴로 산업·보안 이슈가 고르게 걸쳤습니다.

## 논문

### [[GateMem - Benchmarking Memory Governance in Multi-Principal Shared-Memory Agents]]
- 태그: 에이전트, AI평가
- 병원·직장·가정처럼 여러 사람이 한 AI의 메모리를 공유하는 환경을 평가하는 벤치마크입니다. 잘 기억하는 것을 넘어 권한 밖 정보 차단과 삭제 요청 준수까지 측정하는데, 어떤 방법도 유용성·접근제어·능동 망각 세 가지를 동시에 잡지 못했습니다.

### [[PlanBench-XL - Evaluating Long-Horizon Planning of LLM Tool-Use Agents in Large-Scale Tool Ecosystems]]
- 태그: LLM, 에이전트, 벤치마크
- 1,665개 도구 생태계에서 LLM 에이전트의 장기 계획 능력을 측정합니다. GPT-5.4는 도구 차단 조건에서 51.9%에서 11.36%로 붕괴했고, 실패의 핵심은 검색 부족이 아니라 이미 가진 도구를 제대로 고르지 못하는 선택 실패였습니다.

### [[AOHP - An Open-Source OS-Level Agent Harness for Personalized, Efficient and Secure Interaction]]
- 태그: 에이전트, 오픈소스
- AI 에이전트를 OS 1급 시민으로 다루는 AOSP 기반 오픈소스 하네스입니다. 기존 앱 중심 Android 대비 태스크 완료율 +21%, 토큰 비용 -52%, 실행 시간 -44%를 달성했습니다.

### [[Learning from the Self-future - On-policy Self-distillation for dLLMs]]
- 태그: LLM, 확산모델
- 확산 LLM에 온폴리시 자기증류를 처음 적용한 d-OPSD입니다. 모델이 스스로 완성한 미래 답변을 suffix로 조건화해, RLVR 대비 약 10% 최적화 스텝만으로 동급 성능을 냈습니다.

### [[PerceptionDLM - Parallel Region Perception with Multimodal Diffusion Language Models]]
- 태그: 멀티모달, 확산모델
- 베이징대 MSALab과 ByteDance의 멀티모달 확산 언어 모델입니다. 자기회귀가 영역을 하나씩 순차 캡셔닝하는 한계를 깨고 한 번의 디노이징으로 여러 영역을 동시에 설명하며, 구조적 어텐션 마스킹으로 간섭을 막아 최대 3.5배 빠른 추론을 보입니다.

### [[ACE-Ego-0 - Unifying Egocentric Human and Robotic Data for VLA Pretraining]]
- 태그: 에이전트, 컴퓨터비전, 머신러닝
- 비싸고 편향된 로봇 조작 데이터를 인간 1인칭 영상 1,478시간으로 보완한 VLA 사전학습 프레임워크입니다. 공간·구조·시간 세 축의 표현 통합과 신뢰도 가중 보조 손실로 RoboCasa, RoboTwin 2.0 모두에서 최고 성능을 달성했습니다.

### [[DragMesh-2 - Physically Plausible Dexterous Hand-Object Interaction with Articulated Objects]]
- 태그: 강화학습, 컴퓨터비전
- 서랍·문 같은 관절형 오브젝트의 가동 부위를 손-핸들 접촉만으로 움직이는 접촉 주도 프레임워크입니다. PICA가 물리 신호를 PPO에 주입해, 감쇠 4배 조건에서 State-only PPO 대비 두 배 이상의 성공률을 냈습니다.

### [[Zone of Proximal Policy Optimization - Teacher in Prompts, Not Gradients]]
- 태그: LLM, 강화학습
- 교사를 그래디언트가 아닌 프롬프트 안에 가두는 소형 VLM 포스트 트레이닝 방법론 ZPPO입니다. 지식 증류가 OOD 일반화를 훼손하는 반면, ZPPO는 0.8B 학생에서 VLM 벤치마크 +9.3pp를 내면서 훈련 외 도메인까지 개선했습니다.

### [[Unlimited OCR Works - Welcome the Era of One-shot Long-horizon Parsing]]
- 태그: LLM, 머신러닝
- DeepSeek OCR 디코더의 모든 어텐션을 R-SWA로 교체해 KV 캐시를 상수로 유지합니다. 단일 forward pass로 수십 페이지 문서를 파싱하며 OmniDocBench v1.6에서 SOTA 93.92%를 달성했습니다.

## 정보·산업

### [[FERC, AI 데이터센터 전력망 우선순위 문제로 6개 전력 계통운영자에 입증 명령]]
- 태그: 정보, Headliner
- FERC가 2026년 6월 18일 6개 전력 계통운영자에 Section 206 입증 명령을 발령했습니다. AI 데이터센터의 대규모 전력 연계 요청이 기존 대기열을 뒤흔들고 있기 때문입니다.

### [[Sakana Fugu]]
- 태그: 정보, Headliner, LLM, 에이전트
- 여러 프런티어 모델을 동적으로 지휘하는 Sakana AI의 멀티에이전트 오케스트레이션 모델 Fugu를 정리했습니다.

### [[Mastra npm 공급망 공격]]
- 태그: 정보, 에이전트, 오픈소스
- 탈취된 컨트리뷰터 계정으로 @mastra npm 스코프 패키지들이 88분 만에 백도어됐습니다. easy-day-js라는 dayjs 타이포스쿼트가 정보 탈취 페이로드를 심었고, MS는 북한 Sapphire Sleet에 귀속했습니다.

### [[ChatGPT 시장점유율, 역사상 처음으로 50% 아래로]]
- 태그: 정보, LLM, 산업
- Sensor Tower 보고서에 따르면 2026년 3월 ChatGPT의 AI 앱 시장점유율이 46.4%로 하락했습니다. 출시 이후 처음으로 50% 아래로 떨어졌고 Gemini 27.7%, Claude 10.3%가 뒤를 이었습니다.
