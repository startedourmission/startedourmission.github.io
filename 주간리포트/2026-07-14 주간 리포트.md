## 논문

### [[Video Generation Models are General-Purpose Vision Learners]]
- 태그: 컴퓨터비전, 확산모델, 멀티모달
- 비디오 생성 모델의 사전학습 표현을 그대로 활용해 깊이, 법선, 분할, 포즈 같은 여러 비전 과제를 단일 피드포워드 모델로 처리하는 GenCeption을 제안합니다. WAN 2.1을 백본으로 삼아 V-JEPA와 VideoMAE를 큰 폭으로 앞섰고, 전문 모델의 7배에서 500배 적은 데이터로 준하는 성능을 냈습니다. 생성 모델이 사실상 범용 비전 백본이 될 수 있다는 주장입니다.

### [[Scalable Visual Pretraining for Language Intelligence]]
- 태그: LLM, 멀티모달, 컴퓨터비전
- PDF 페이지를 텍스트로 뽑지 않고 이미지 그대로 오토리그레시브 학습하면, 같은 코퍼스를 텍스트만으로 학습한 것보다 과학 추론 성능이 일관되게 높아진다는 실증 연구입니다. 상하이 AI 연구소가 주축이며, MMLU-Pro와 GPQA, AIME에서 텍스트 대비 배수 단위 향상을 보고합니다. 문서를 시각 신호로 다루는 것이 언어 지능에도 이득이 된다는 관찰입니다.

### [[The Illusion of Equivalency - Statistical Characterization of Quantization Effects in LLMs]]
- 태그: LLM, AI평가
- 양자화한 LLM을 정확도와 퍼플렉시티만으로 보면 원본과 같아 보이지만, 실제로 맞히는 문제의 집합은 달라진다는 점을 짚습니다. correctness agreement라는 결정 수준 지표를 도입해 총점이 유지돼도 어떤 문제에서 갈리는지 드러내고, 8비트에서 2비트까지 훑으며 어텐션의 쿼리와 키 투영이 가장 취약함을 보입니다. 양자화 평가를 총점 대신 결정 일치로 봐야 한다는 제안입니다.

### [[AutoMem - Automated Learning of Memory as a Cognitive Skill]]
- 태그: LLM, 에이전트
- 메모리 관리를 아키텍처에 박아넣는 고정 모듈이 아니라 학습 가능한 기술로 다룬 연구입니다. 파일 시스템 조작을 과제 행동과 동급으로 올리고, 메타 LLM이 궤적을 검토해 골격과 숙련을 함께 최적화합니다. 가중치를 건드리지 않고 메모리만 손봐도 Qwen2.5-32B의 장기 과제 성능이 두세 배 올랐습니다.

### [[Vision Pretraining for Dense Spatial Perception]]
- 태그: 컴퓨터비전, 딥러닝
- 의미 불변성에 치우친 시각 사전학습이 조밀한 공간 정보를 잃는 문제를 경계 중심 자기지도학습으로 다룹니다. LingBot-Vision은 경계 토큰을 의도적으로 가리고 의미와 기하를 함께 복원해, 깊이 추정과 분할에서 DINOv3나 V-JEPA 2.1에 견주는 성능을 더 작은 규모로 냅니다. 표현이 무엇을 버리고 있는지를 경계에서 되짚은 접근입니다.

## 모델 릴리스

### [[Grok 4.5]]
- 태그: LLM
- xAI가 Cursor와 협력해 출시한 코딩 특화 모델입니다. 1.5조 파라미터 V9 MoE 아키텍처에 Cursor 실사용 세션 데이터를 훈련 신호로 넣어, IDE 작업 흐름에 맞춘 점이 특징입니다. 절대 점수 최상위는 아니지만 SWE-Bench Pro 작업 하나를 경쟁 모델의 약 4.2배 적은 토큰으로 처리해, 에이전트 반복 호출이 많은 파이프라인에서 비용 우위를 노립니다.

### [[GPT-5.6와 ChatGPT Work]]
- 태그: LLM
- OpenAI가 GPT-5.6 3종(Sol, Terra, Luna)과 업무 에이전트 ChatGPT Work를 같은 날 냈습니다. 최상위 Sol은 하위 에이전트로 분해해 병렬 처리하는 ultra 모드를 갖고, ChatGPT Work는 연결된 앱과 파일에서 맥락을 모아 문서와 스프레드시트, 발표자료를 산출합니다. 경쟁축이 모델 성능에서 업무 실행으로 옮겨간 발표입니다.

### [[Claude Science - Anthropic의 과학자용 AI 연구 워크벤치]]
- 태그: 에이전트, AI평가
- Anthropic이 과학 연구자를 위해 공개한 에이전트 기반 워크벤치입니다. 코디네이터 에이전트가 60개 이상의 큐레이션 스킬을 골라 호출하고, 리뷰어 에이전트가 인용과 계산값을 코드 결과와 대조해 자기교정합니다. Manifold Bio의 후보 타깃 선정, Allen Institute의 문헌 리뷰 자동화 같은 실사용 사례와 함께 나왔습니다.
