> [!summary] 지난 7일 (2026-07-02 ~ 07-08) 요약
> 게시 18편(논문 11, 정보 6, 잡담 1). 논문이 절반 이상으로 에이전트 메모리·벤치마크(AgenticSTS, MemSyco-Bench, EvoPolicyGym, TUA-Bench)와 확산 가속·양자화(OrbitQuant, MrFlow, LiveEdit)에 몰렸습니다. 정보 글은 모델 릴리스 2편(Sonnet 5, Nano Banana 2)과 대형 펀딩·주정부 도입 등 산업·비즈니스 4편으로 갈렸고, 툴·오픈소스 테마는 이번 주 공백입니다.

## 논문

### [[Verbalizable Representations Form a Global Workspace in Language Models]]
- 태그: LLM, 추론
- Anthropic이 언어모델 내부에서 인간의 접근의식(access consciousness)과 유사한 신경 표상 집합(J-space)을 발견했습니다. 모델이 겉으로 드러내지 않는 순간에도 무엇을 생각하는지 읽어낼 수 있고, 실제 안전성 모니터링에 활용되고 있습니다.

### [[OrbitQuant - Data-Agnostic Quantization for Image and Video Diffusion Transformers]]
- 태그: 확산모델, 컴퓨터비전
- DiT 활성화의 타임스텝·프롬프트별 드리프트를 회전 정규화로 고정하고, 단일 코드북으로 캘리브레이션 없이 가중치와 활성화를 동시에 양자화합니다. 다른 방법이 모두 붕괴하는 W2A4 극저비트에서 유일하게 생성 품질을 유지했습니다.

### [[Embodied.cpp - A Portable Inference Runtime of Embodied AI Models on Heterogeneous Robots]]
- 태그: 에이전트, 오픈소스
- VLA·WAM 모델을 이기종 로봇 에지 기기에서 실행하는 C++ 5레이어 추론 런타임입니다. Python 스택 단편화를 아키텍처적으로 풀고 HY-VLA 100%, pi0.5 91% 태스크 성공률을 보고합니다.

### [[AgenticSTS - A Bounded-Memory Testbed for Long-Horizon LLM Agents]]
- 태그: LLM, 에이전트
- 에이전트 메모리를 "얼마나 많은 히스토리를 넣느냐"가 아니라 "어느 레이어가 결정을 바꾸느냐"로 측정하는 게임 테스트베드입니다. Slay the Spire 2 위에서 5층 타입 메모리 계약을 구현하고 298개 궤적을 공개했습니다.

### [[Multi-Resolution Flow Matching - Training-Free Diffusion Acceleration via Staged Sampling]]
- 태그: 확산모델, 컴퓨터비전
- 재훈련 없이 FLUX·Qwen-Image 같은 플로우 매칭 모델을 10배 가속하는 MrFlow입니다. 초반 스텝은 저해상도 잠재 공간에서 처리하고, 마지막은 1스텝 고해상도 정제로 마무리하는 단계별 파이프라인입니다.

### [[MemSyco-Bench - Benchmarking Sycophancy in Agent Memory]]
- 태그: LLM, 에이전트, 벤치마크
- 에이전트 메모리가 저장된 사용자 기억에 무조건 동조하는 "메모리 아첨"을 처음으로 체계화한 벤치마크입니다. 언제 기억을 무시·제약·활용해야 하는지 판단력을 5개 태스크로 평가합니다.

### [[ELDR - Expert-Locality-Aware Decode Routing for PD-Disaggregated MoE Serving]]
- 태그: LLM, GPU
- Prefill-Decode 분리 환경에서 MoE decode 지연을 5.9~13.9% 줄이는 ELDR입니다. Prefill 단계의 전문가 활성화 서명을 활용해, 이미 해당 가중치를 캐시한 워커로 decode 요청을 라우팅합니다.

### [[Program-as-Weights - A Programming Paradigm for Fuzzy Functions]]
- 태그: LLM, 오픈소스
- 자연어로 명세한 함수를 경량 LoRA 어댑터로 컴파일해 로컬 실행하는 퍼지 함수 프로그래밍 패러다임입니다. 0.6B 인터프리터가 메모리를 50분의 1로 쓰면서 Qwen3-32B를 뛰어넘습니다.

### [[EvoPolicyGym - Evaluating Autonomous Policy Evolution in Interactive Environments]]
- 태그: 강화학습, 에이전트, 벤치마크
- 에이전트가 실행 가능한 정책 코드를 128 에피소드 예산 안에서 반복 개선하는 능력을 측정하는 벤치마크입니다. GPT-5.5가 Core16 전 환경에서 Top-2, Claude Opus 4.7이 MiniGrid에서 가장 강한 두각을 보였습니다.

### [[TUA-Bench - A Benchmark for General-Purpose Terminal-Use Agents]]
- 태그: 에이전트, 벤치마크
- 터미널 환경에서 범용 에이전트를 평가하는 120개 태스크 벤치마크입니다. 가장 강한 Claude Code + Opus 4.8 구성도 65.8% 성공률에 그쳤고, Office와 Multimedia에서 공통으로 막히는 패턴이 드러났습니다.

### [[LiveEdit - Towards Real-Time Diffusion-Based Streaming Video Editing]]
- 태그: 영상처리, 확산모델
- 청화대와 HKUST가 제안한 스트리밍 비디오 편집 프레임워크입니다. 3단계 확산 증류와 AR-oriented Mask Cache를 결합해 InsV2V 대비 지연을 97배 줄이고 12.66 FPS 실시간 편집을 달성했습니다.
